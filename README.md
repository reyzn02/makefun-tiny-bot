A tiny paper-trading bot for hourly Solana prices: it rotates into the top 2 symbols by EMA tilt plus trailing 24-bar return, rebalances every 12 bars, and cuts any position that falls 6% below its entry. Long only, no leverage, deterministic.

## Run it

```sh
python3 main.py
```
